# YunoBall — agent instructions

Monorepo: `apps/web` (Next.js 15 app-router UI), `apps/server` (Express/TS
API + rule-based query engine + nflverse ingest), `packages/types` (shared
wire types), Postgres warehouse (Docker :5432 local, Supabase prod). All
numbers computed from nflverse data.

## The rule

**Before making any change, read its canonical doc.** If your change conflicts
with the doc, apply the change AND update the doc in the same commit. A
canonical doc that drifts is worse than no doc.

| Changing… | Read first |
|---|---|
| The query engine, intents, stats | [TDD.md](docs/TDD.md) |
| Warehouse tables, columns, ingest | [BACKEND_SCHEMA.md](docs/BACKEND_SCHEMA.md) |
| The fact miner / probes | [FACTS.md](docs/FACTS.md) |
| System structure, services, layering | [ARCHITECTURE.md](docs/ARCHITECTURE.md) |
| Anything visual — color, type, spacing | [DESIGN_BRIEF.md](docs/DESIGN_BRIEF.md) |
| Components and page chrome | [FRONTEND_SPEC.md](docs/FRONTEND_SPEC.md) |
| Routes, navigation, user journeys | [APP_FLOW.md](docs/APP_FLOW.md) |
| Deploys, workflows, env | [DEPLOYMENT.md](docs/DEPLOYMENT.md) |
| Scope and what ships | [PRD.md](docs/PRD.md) · [ENGINEERING_PLAN.md](docs/ENGINEERING_PLAN.md) |

Docs are **markdown-first**: `docs/*.html` is generated by `pnpm docs:build`.
Edit the `.md`, run the build, commit both. Never hand-edit a generated page
(`FRONTEND_SPEC.html` is the one exception — it renders live component demos
against the app stylesheet and is maintained by hand).

## Hard invariants (the ones that break things)

- **Never run `next build` while the dev server is running** — corrupts `.next`.
- **Never a wrong number**: the engine refuses what it can't answer precisely
  (see [TDD.md](docs/TDD.md) before touching `src/engine/`).
- **nflverse only** for data; never scrape Pro-Football-Reference.
- **Facts are mined, never generated** — the fact of the day comes from
  reviewed SQL probes and templated headlines, and no claim may reach past its
  derived coverage floor (see [docs/FACTS.md](docs/FACTS.md) before touching
  `src/facts/`).
- Wire-format changes touch server + `packages/types` + web **together**.
- Style only with tokens/`yb-*` classes; team colors only via `teamTheme()`.

## Verification battery

```bash
pnpm typecheck && pnpm lint && pnpm knip   # must all pass before committing
pnpm --filter @yunoball/server test        # DB-backed suites need Postgres up
pnpm docs:build                            # after any docs/*.md edit
```

`docker compose up -d` starts the local Postgres the ingest and DB-backed test
suites (`ingest.test.ts`, `sweep.test.ts`) need; without it those suites can't
run and CI is the first thing that exercises them.
